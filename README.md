# Retainr Website v2

A simple, modern, blazing-fast, and SEO-optimized marketing website for **Retainr.io** — The focused retainer engine that turns freelance services into predictable monthly recurring revenue on full autopilot. Built with Astro 🚀🪄

## 📄 Overview

[![Ko Fi - Offer Me A Coffee](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/phenry)

**Modern. Fast. Conversion-Focused.** Just what you need to showcase and sell Retainr.io to freelancers, indie hackers, and small agencies 🧹

Retainr.io helps creators escape the feast-or-famine cycle by automating proposals, client onboarding, delivery scheduling, payments, renewals, and retainer health tracking — all in a beautiful white-label client portal.

## 🟢 Requirements
* [Node.js](https://nodejs.org/) v18.14 or newer.
* npm (or pnpm/yarn).

## 🛠 Installation

```bash
npm install
```

## 🥳 Usage

Start the local development server (bound to 127.0.0.1):

```bash
npm run dev
```

Build the optimized static site for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The live site is deployed at [https://www.retainr.io](https://www.retainr.io)
